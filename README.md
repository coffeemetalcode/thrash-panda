# Thrash Panda

Webbie for Thrash Panda 804

## Local Development

1. Clone the repo
1. `cd thrash-panda`
1. `nvm install` (or `nvm use`)
1. Ensure Angular CLI v21 is installed - `ng --version`
1. If not installed, then `npm i g @angular/cli@21`
1. `npm i`
1. `npm start`
1. App starts in 'watch' mode
1. Browse to [http://localhost:4200](http://localhost:4200) to audition changes

## Update Site

1. Create a new branch
1. Make changes, commit, open a PR
1. Test changes, merge PR
1. Publish

## Publishing

1. `git checkout main`
1. `npm run deploy`
1. Static site will be deployed via Github Pages
1. Published site is viewable at [https://thrashpanda804.com](https://thrashpanda804.com)

## Stack

- Angular 21
- Node 22
